# Abirami R — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and JavaScript. The design uses a dark cosmic theme inspired by my interests in AI, data science, and astronomy.

## Sections
- Hero and profile links
- About me
- Technical skills
- Featured projects
- Education, certification, achievements, and soft skills
- Contact links and resume

## Run locally
Open `index.html` in your browser. No build tools are required.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `abirami-portfolio`.
2. Extract this ZIP file.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
4. Commit the files.
5. Open **Settings → Pages** in the repository.
6. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
7. After GitHub Pages finishes deploying, your portfolio will be available at `https://YOUR-USERNAME.github.io/abirami-portfolio/`.

## Before publishing
- Replace the project links that currently point to your GitHub profile with the exact repository URLs for each project.
- Confirm that your LinkedIn and LeetCode links are correct.
- The resume PDF is included in `assets/ATS_resume.pdf`.
- If you do not want your resume publicly downloadable, remove the PDF and remove the resume links from `index.html`.
